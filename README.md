### 🚀 Featured Data Science Projects

#### 1. Timeseries Analysis for Sales and Demand Forecasting
- **Business Problem:**  Identify sales patterns, seasonal trends to inform reordering, restocking, and reprinting decisions for various books.
- **Solution:** Developed SARIMA, XGBoost and LSTM pipelines for forecasting. 
- **Impact & Metrics:** On average produced forecasts with **MPE scores** within the **15-25%** range. 
- **Repository:** [View Code & Report](https://github.com/Fu11ee-wave-E/Time_Series_Analysis_for_Sales_and_Demand_Forecasting.git)

#### 2. Supervised Learning to Predict Student Dropout
- **Business Problem:** Used demographic and administrative anonymised records of over 25,000 international students to predict dropout rates. 
- **Solution:** Developed XGBoost and NN based pipelines to predict student dropout.
- **Impact & Metrics:** The predictions surpassed the **75% TPR** threshold indicating well-performing models for the given scenario.
- **Repository:** [View Code & Learn More](https://github.com/Fu11ee-wave-E/Applying_Supervised_Learning_to_Predict_Student_Dropout.git)

#### 3. Customer Segmentation with Clustering
- **Business Problem:**  Help an e-commerce company, with a transatlantic customer base, understand its customers to derive customer-centric insights.
- **Solution:** Performed k-means and hierarchical clustering, implemented tatistical approaches such as within-cluster variation and silhouette score 
analyses and produced visualisations using PCA and t-SNE. 
- **Impact & Metrics:** Determined the optimal number of clusters, 𝑘, for the e-commerce dataset.
- **Repository:** [View Code & Report](https://github.com/Fu11ee-wave-E/Customer_Segmentation_with_Clustering.git).

#### 4. Detecting Anomalous Activity of a Ship's Engine
- **Business Problem:** Creating a reliable anomaly detection system to mitigate potential safety hazards and significant downtime that can arise from a poorly maintained ship engine.
- **Solution:** Applied a statistical approach incorporating the interquartile range (IQR) , followed by two unsupervised ML models: One-Class Support Vector Machine and Isolation Forest.
- **Impact & Metrics:** Determined the flagged feature threshold required for a true anomaly and accounted for roughly 37% of variance in the dataset.
- **Repository:** [View Code & Learn More](https://github.com/Fu11ee-wave-E/Detecting_Anomalous_Activity_of_a_Ship_Engine.git)
